**October 1, 2026: Axon provides a locally hosted, cross-harness agent-to-agent communication protocol for Claude Code, Codex, OpenCode, and Hermes, installed through hooks without a wrapper, governed by edges, link/accept, and grants, audited, and displayed live as dashboard message arcs.** This lets developers coordinate agents across harness boundaries while inspecting their conversations and controlling permitted routes (`crates/axon-bus/src/hook.rs:181`, `crates/axon-bus/src/install.rs:66`, `crates/axon-bus/src/route.rs:109`, `crates/axon-bus/src/msg.rs:118`, `crates/axon-bus/src/serve.rs:280`, `crates/axon-bus/ui/arcs.js:11`).

The protocol has concrete boundaries: parent/child edges are automatic, root links require reciprocal acceptance, and temporary grants shortcut an existing route for one thread (`crates/axon-bus/src/route.rs:44`, `crates/axon-bus/src/route.rs:58`, `crates/axon-bus/src/route.rs:76`). `send` checks those edges; `reply` checks the question's addressee and preserves its thread (`crates/axon-bus/src/msg.rs:59`, `crates/axon-bus/src/msg.rs:233`). Agents receive their identity, reachable peers, repository neighbors, and playbook instructions through hooks (`crates/axon-bus/src/roster.rs:31`, `crates/axon-bus/src/roster.rs:132`; `crates/axon-bus/src/guide.rs:6`). The relay runs supported standalone shell commands as the caller, with time/output limits; blocking `ask` and chained commands are excluded (`crates/axon-bus/src/relay.rs:39`, `crates/axon-bus/src/relay.rs:63`, `crates/axon-bus/src/relay.rs:150`). Delivery waits for supported hook events (`crates/axon-bus/src/gate.rs:72`); the command guard does not parse script indirection (`crates/axon-bus/src/cli_guard.rs:1`).
